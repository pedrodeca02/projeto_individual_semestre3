# projeto_individual_semestre3
# 🐾 API Pet Shop

## Sobre o projeto

Projeto de uma **API para Pet Shop**, desenvolvida com **Spring Boot, Java, JDBC e MySQL**, com um front-end simples em **React + JSX** para consumir os dados.

## Objetivo da Sprint 1

Na primeira sprint, o foco será criar a estrutura inicial do sistema com:

* Cadastro de pets;
* Cadastro de donos;
* Conexão local com MySQL;
* Integração entre React e Spring Boot.

## Endpoints

* `GET /pets` — lista os pets cadastrados;
* `POST /pets` — cadastra um novo pet.

## Tecnologias

* Java
* Spring Boot
* JDBC
* MySQL
* React
* JSX

## Resultado esperado

Ao final da Sprint 1, será possível **cadastrar e visualizar pets**, com os dados sendo salvos no banco MySQL através da API.
