# PetShop Front

Front-end em React + JSX para o projeto individual de API PetShop.

## Estrutura

- `src/componentes/`: componentes reutilizáveis.
- `src/pages/`: telas da aplicação.
- `src/App.jsx`: controla a navegação simples entre cadastro e listagem.
- `src/index.css`: estilos globais.
- CSS Modules são usados em cada componente/tela.

## Como executar

```bash
npm install
npm run dev
```

## Sprint 1

- JSX;
